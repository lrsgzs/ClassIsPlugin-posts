如果有创作上的疑问，可以联系 QQ 2738046906 (lrsgzs/lrs2187)。

## 仓库结构

`drafts` 目录存放草稿，文章应在单独目录存放，建议使用英文名。如：`startup-public`。

`posts` 目录存放发出后的文章，文章应在单独目录存放，以 `{编号}-{草稿名}` 为文件夹名。
贡献者请勿操作这里面的内容，此文件夹一般由 lrsgzs 操作。

### 文章结构

- `CONTENT.md`：文章 markdown 内容。
- `assets`文件夹 (可选)：存放资源文件，文件名应尽量清晰。
- `assets/banner.png` (可选)：封面图片文件。

## 贡献

您应直接贡献 markdown 内容和资源文件。可以直接在 <https://vuemd.lrsgzs.top/> 预览 markdown 渲染结果。
如您未特殊声明，推文发布时会通过该网站渲染后，在公众号编辑器进行微调排版。
如果您需要用自定义网站渲染，请给出可访问网站链接。

### 关于封面...

一般情况下 lrs2187 会根据文章内容，找 LiPolymer 画封面。
如果您想自已画封面，可联系 lrs2187 的 QQ 获取 figma 文件链接、询问相关事宜。
